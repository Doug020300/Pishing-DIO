Simulação de Phishing em Ambiente Controlado
Descrição
Este projeto demonstra uma simulação de phishing realizada em ambiente controlado utilizando o sistema operacional Kali Linux para fins exclusivamente educacionais e de conscientização em segurança da informação.

O objetivo é entender como ataques de engenharia social funcionam, identificar vulnerabilidades humanas e estudar formas de prevenção contra roubo de credenciais.

⚠️ Aviso Importante: Este projeto foi desenvolvido apenas para estudos em laboratório autorizado. O uso indevido de técnicas de phishing contra terceiros sem autorização é ilegal e antiético.




Tecnologias Utilizadas
Kali Linux
Ferramentas de segurança ofensiva
Terminal Linux
Engenharia social (simulação)




Objetivos do Projeto
Demonstrar conceitos de engenharia social
Estudar ataques de coleta de credenciais
Entender riscos relacionados a páginas falsas
Aprender medidas de prevenção e conscientização
